# Metasiberia Beta v0.0.25

Дата: 2026-10-12

## Главное

Этот выпуск объединяет текущие изменения Qt-клиента и исходников Linux-сервера после v0.0.24. В клиенте версия 0.0.25 отображается в заголовке окна и окне «О программе».

## Моделирование и ИИ

- Расширены MCP-инструменты для редактируемых mesh, геометрических операций, риггинга, параметрических конструкций, деревянных стен из бруса и брёвен, работы по фотографиям и размерным чертежам.
- Добавлены инструменты преобразования текста в mesh, управления редактором анимаций и подробная справка для программирования объектов на Luau.
- Улучшены инструкции Codex: построение по этапам, проверка геометрии и ракурсов, сохранение кода в скрипте выбранного объекта.

## Редактор и инвентарь

- В редакторе текста сохранены позиция курсора и выделение при обновлении объекта; выбор шрифта учитывает символы текущего текста.
- Улучшены предпросмотр и настройка предметов снаряжения, взаимодействие с гизмо и изображение предмета в инвентаре.
- Добавлен экспорт выбранного объекта в GLB с проверкой прав; ограничены копирование и клонирование чужих объектов.
- Доработаны инструменты удаления растительности и совместимость отображения аватаров со старыми клиентами.

## Совместимость и проверка

- Для новых серверных MCP-инструментов нужен активный совместимый Linux-сервер и новая сессия ИИ после обновления клиента. Исходники сервера входят в архив исходного кода; Windows-сервер и SDL-клиент в этот выпуск не собираются.
- Выпускной Windows Qt-клиент и NSIS-установщик собираются локально. Установщик `MetasiberiaBeta-Setup-v0.0.25.exe` владелец релиза загрузит в GitHub Release вручную.
- Новые возможности моделирования требуют визуальной проверки на конкретных сценах; наличие инструмента не гарантирует точного восстановления формы по одному изображению.
