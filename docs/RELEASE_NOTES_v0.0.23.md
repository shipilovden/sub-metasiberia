# Metasiberia Beta v0.0.23

Дата: 2026-09-25

## Главное

Metasiberia Beta v0.0.23 — релиз исправлений клиентского жизненного цикла, загрузки ресурсов и редактора объектов, а также обновлений Metasiberia Web и проектной документации.

## Исправления текстур и редактора объектов

1. Исправлен случай, когда материал объекта становился белым, если серверная уменьшенная версия текстуры (`LOD`) отсутствует.
2. Клиент теперь использует доступную оригинальную текстуру как fallback, сохраняя при этом подписку на требуемую LOD-версию.
3. Когда отсутствующая LOD-версия появляется позже, она может заменить fallback без повторного редактирования объекта.
4. Fallback работает для объектов и аватаров, включая пустой локальный кэш и загрузку оригинала после подтверждённого отказа сервера.
5. Сохранены исходные параметры цветового пространства и сжатия; normal map и roughness map не загружаются ошибочно как sRGB.
6. Устранены лишние повторные загрузки одной и той же текстуры в WebClient при переходе между callback и обработкой результата.
7. Исправлено оформление пользовательского заголовка dock-панели редактора: фон и цвет теперь локально следуют активной теме, включая floating и redocking панели.

## Запуск и завершение программы

1. Завершение GUI теперь защищено от повторного уничтожения ресурсов после закрытия UI и OpenGL-контекста.
2. Остановка loader, world/network и связанных подсистем получила безопасный порядок завершения и диагностические точки времени.
3. Уменьшены лишние операции при восстановлении чата и применении тем интерфейса.
4. Preview аватара и связанные таймеры корректно останавливаются при закрытии, чтобы не обращаться к уже уничтоженному Qt/OpenGL состоянию.
5. Сетевые потоки клиента и sender корректно завершают работу с отменой и ограниченным ожиданием.

## Клиент, WebClient и ресурсы

1. Добавлена явная обработка ошибки загрузки ресурса для native и Emscripten путей.
2. Общие consumers одной текстуры объединяются до завершения загрузки, поэтому уход одного объекта не лишает остальные результата.
3. Для Emscripten добавлена проверка активного URL, предотвращающая дублирование одновременных загрузок.
4. Изменения общего GUIClient-кода проверены отдельной Emscripten-сборкой `gui_client`; Qt-зависимости не добавлялись в общий SDL/Web путь.
5. Сохранены существующие исправления WebClient для fallback avatar/model resources и изоляции Qt-only редакторов.

## Metasiberia Web и документация

1. Обновлены webserver handlers, public CSS и client-side site logic.
2. Добавлены и синхронизированы публичные служебные ресурсы сайта: verification-файлы, robots.txt, sitemap.xml и основной графический ресурс.
3. Добавлены актуальные инструкции проекта `AGENTS.md`, документы о сайтах Metasiberia и сравнение downstream fork с upstream Substrata.
4. Уточнены канонические Qt и Emscripten build workflows, runtime validation и границы между source, build output и WebClient bundle.
