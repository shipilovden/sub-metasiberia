# NeuroControl architecture

The Qt client separates signal acquisition, signal display, research analysis, and avatar-command policy. EEG sources provide samples and source metadata through a common acquisition interface. The interface can display samples while diagnostics track connection state, sample rate, timestamps, and receiver arrival timing.

For LSL, source-provided timestamps and local monotonic arrival times are separate measurements. Diagnostics may assess timestamp quality, pauses, and observed receive rate; they do not silently replace source timestamps with a reconstructed clock.

Live LSL has an explicit, opt-in shadow-classification path. A shared `LslShadowPipeline` maps selected EEG channels, consumes voltage-normalized frames, tracks stream continuity, resets FIR/classifier state after invalid frames, timestamp gaps, queue overflow, connection loss or reconnection, and applies a causal anti-alias FIR resampler before optional diagnostic classification. The live compatibility gate requires a supported nominal rate, unique model-channel mapping, supported voltage units, five one-second receive-rate measurements, and a known matching montage/reference or separate operator confirmation when metadata is missing. The five-second gate allows a mean difference of at most 3% (or 2 Hz) and a rate-window span of at most 12% (or 10 Hz); these are conservative engineering gates, not validated device tolerances. Known mismatches block classification. Results are diagnostic only and never submit avatar commands.

The local `neuro.audit_lsl_recording` MCP operation verifies a completed `.nlsr` and sends its frames through that same pipeline and FIR resampler. It reports aggregate counts, processing time, non-finite values, timestamp summaries and compatibility blockers, but it does not run the archived classifier or issue avatar commands. Stored arrival times are per-chunk values and may repeat, so offline audit cannot establish source production rate or substitute for the live receive-rate gate. Source timestamps remain separately qualified; poor timestamp resolution prevents claims about device latency or sample loss. The existing avatar command-processing path is unchanged. Enabling one feature does not imply that another is connected, so inspect the source and control state before each action.
