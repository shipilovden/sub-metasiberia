# Словарь NeuroControl

- **ЭЭГ (EEG):** регистрация электрических потенциалов, измеренных электродами на коже головы.
- **BCI / нейроинтерфейс:** система, которая обрабатывает сигналы и передаёт ограниченную команду интерфейсу или устройству.
- **Двигательное воображение (MI):** мысленное представление движения без обязательного фактического движения.
- **LSL:** протокол публикации и получения синхронизированных потоков измерений и метаданных.
- **EDF / EDF+:** форматы записи биосигналов; EDF+ также предусматривает аннотации.
- **BDF:** формат биосигналов с более высоким разрешением отсчётов.
- **F32:** подготовленный поток чисел IEEE-754 float32; формат NeuroControl использует отдельные метаданные.
- **Частота дискретизации:** количество отсчётов канала за секунду.
- **Timestamp источника:** временная метка, переданная производителем потока.
- **Время получения:** локальная монотонная отметка, записанная принимающим клиентом при поступлении данных.
- **CSP:** метод построения пространственных признаков для заданных классов сигналов.
- **LDA:** линейный классификатор, который разделяет классы по их признакам.
- **Порог:** настроенная граница оценки модели, используемая политикой решения.
- **STOP:** защитная команда остановки; она имеет приоритет в политике управления.

Термины описывают обработку сигнала. Они не означают клиническую интерпретацию результата.
