# Локальные инструкции: `substrata`

Дополняет [общие правила](../AGENTS.md). Эти правила обязательны для проекта Metasiberia.

## Сервер и запрещённые сборки

- Сервер Metasiberia работает на Linux. Никогда не собирать Windows target `server`/`server.exe`: локальная Windows-сборка сервера не нужна и не подтверждает production Linux runtime.
- Никогда не собирать SDL-клиент или Emscripten/Web-клиент (`USE_SDL=ON`), включая configure/build для проверки. Не запускать SDL build scripts и не создавать SDL runtime artifacts.
- Windows Qt `gui_client` — отдельный клиентский target; это правило не запрещает его сборку, когда она нужна для задачи.
- Если требуется проверить серверный C++ код, использовать только доступное Linux окружение/CI workflow. Не подключаться к production, не собирать на production и не активировать релиз без отдельного явного задания пользователя. Если Linux проверка недоступна, сообщить это и ограничиться статической проверкой.

## Граница платформ

- Qt desktop — поддерживаемый клиентский путь. Не выводить поддержку SDL/Emscripten из общих headers или старой документации: SDL/Emscripten targets для этого проекта не собирать.
- При изменениях общего кода сохранять существующие platform boundaries и не добавлять зависимости, ломающие Qt-клиент или Linux-сервер.
- Web/SDL исходники и документация могут читаться для понимания, но это не разрешает запускать их configure/build, preload, cache-hash или publish pipeline.
