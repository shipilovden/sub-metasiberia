# Metasiberia Beta v0.0.26

Дата: 2026-11-10

## Главное

Выпуск объединяет изменения клиента и серверных интерфейсов моделирования после v0.0.25. Версия 0.0.26 отображается в заголовке клиента и окне «О программе».

## Редактор мира и моделирование

- Восстановлены и перестроены инструменты редактора вокселей; улучшены множественный выбор, групповое перемещение и обработка ошибок объединения объектов.
- Добавлены прямоугольные формы порталов и улучшено редактирование рельефа и настроек мира.
- Улучшены обнаружение аватаров, ограничения операций с mesh и физический профиль для пользовательской высоты аватара.
- Доработаны преобразование 3D-текста и обновление шрифтов.

## Codex, MCP и программирование

- Улучшены чат ИИ и соединение Blender с Metasiberia; расширены MCP-инструменты управления миром и моделирования.
- Расширены Lua API событий и объектов.
- Добавлены runtime плагинов и pipeline получения данных NeuroControl через LSL.

## Клиент и совместимость

- Добавлена поддержка ссылок `sib://` при сохранении совместимости с `sub://`.
- Доработаны Qt runtime safeguards, а также интерфейсы рельефа, редакторов, чата и фоторежима.
